# Fashion Forecasting Lab — versioni scaricabili

Qui si trovano **solo gli installabili** di Fashion Forecasting Lab (programma per Windows per analizzare i dati di
Google Trends e fare previsioni di tendenza nella moda). Scarica l'ultima versione dalla sezione **Releases**.
Il codice sorgente non è in questo repository.

## Informazioni importanti

- **Programma indipendente**: non è affiliato, sponsorizzato né approvato da Mistral AI, Google, Plotly, Microsoft,
  Ollama o altre aziende citate. I nomi e i marchi appartengono ai rispettivi proprietari.
- **I tuoi dati restano sul tuo computer.** Il programma non scarica dati da Google Trends in automatico: i file CSV li
  scarichi tu dal sito di Google Trends.
- **Licenze dei componenti**: l'elenco completo è nel file `THIRD_PARTY_NOTICES.txt`, allegato a ogni release e
  consultabile nel programma («Licenze e crediti»).
- **Timestral (modulo opzionale)**: modello di Mistral AI per le previsioni, non incluso nel programma. Se scegli di
  installarlo, viene scaricato sul tuo PC dalle fonti ufficiali. Il codice è Apache 2.0; i pesi hanno licenza «Modified
  MIT» di Mistral AI, che **non ne consente l'uso se il fatturato mensile consolidato della tua azienda (o del tuo
  datore di lavoro) supera 20 milioni di dollari**.
- Il programma è fornito «così com'è», senza garanzie. Le previsioni sono ipotesi statistiche, non consulenza
  finanziaria.
